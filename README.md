# Call Recorder

An Omarchy Shell plugin that records the default desktop output and a selected
microphone into a single MP3 file.

Plugin id: `illegalstudio.omarchy-call-recorder`.

Start it from `Capture > Record call audio`. While recording, the red icon in
the right side of the bar opens controls for audio levels, microphone selection,
pause, source muting, and stop.

Files are saved in `~/Music/Recordings/` and can be uploaded directly to Plaud
Web.
